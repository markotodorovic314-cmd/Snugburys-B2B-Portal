# Snugburys — B2Bware portal demo

Ovaj paket sadrži poseban buyer portal i admin prikaz kao interaktivnu demonstraciju.

- Buyer: `index.html` — korisničko ime: `demo`, lozinka: `B2Bware2026` (već su popunjeni).
- Admin: `admin.html` — link postoji i na stranici za prijavu i u buyer meniju.
- Probaj kupovinu: dodaj proizvode u korpu, potvrdi demo narudžbinu i otvori admin prikaz u istom pregledaču. Promena demo statusa u adminu je vidljiva u buyer prikazu nakon osvežavanja.
- Demo podaci se čuvaju lokalno u pregledaču; ne postoji prava registracija, obrada porudžbina, plaćanje niti ERP integracija. Javna lozinka nije stvarna zaštita pristupa.
- Cene u GBP, raspoloživost, kupac, stanje kredita i fakture su primeri. `DEMO-` šifre su izmišljene; ako su javne maloprodajne šifre dostupne, to je označeno u katalogu.
- Podaci, pakovanja i slike mogu se promeniti; potvrdi aktuelni katalog pre slanja.

## GitHub Pages

1. Napravi odvojen repozitorijum za ovu firmu.
2. Raspakuj ZIP i ubaci SVE fajlove i folder `assets` direktno u koren repozitorijuma; `index.html` mora biti u korenu.
3. U Settings → Pages izaberi Deploy from a branch, zatim `main` i `/ (root)`.
4. Buyer link je adresa GitHub Pages sajta; za admin dodaj `/admin.html` na kraj adrese.
